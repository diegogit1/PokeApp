# 📱 Proyecto Académico: App Android con Kotlin Compose y PokeAPI

## 📌 Descripción

Este repositorio contiene un **trabajo académico** que consiste en el desarrollo de una aplicación móvil Android utilizando **Kotlin**.

La app realiza llamadas a **PokeAPI** para obtener y mostrar todos los Pokémon pertenecientes a la región de **Kanto (1 - 151)**, presentándolos en una interfaz moderna y fácil de usar.

---

## 🎯 Objetivo

Desarrollar una aplicación Android que consuma datos desde una API pública y los muestre de forma dinámica, aplicando buenas prácticas de desarrollo y diseño.

---

## 🧩 Funcionalidades principales

* Listado de Pokémon de Kanto
* Consumo de datos desde PokeAPI
* Interfaz creada con Jetpack Compose
* Diseño basado en Material Design
* Manejo de estados de carga y error

---

## 🛠️ Tecnologías utilizadas

* Kotlin
* Jetpack Compose
* Retrofit
* PokeAPI
* Material Design
